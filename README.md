# regresion_lineal_fz
Ejercicio de regresión lineal, predicción de consumo de una yamaha fz 2.0

## 📖 Descripción del Proyecto

Este proyecto implementa un modelo de **Machine Learning** (Regresión Lineal Simple) para predecir el consumo de combustible de una **Yamaha FZ 2.0** basándose únicamente en la distancia recorrida en kilómetros.

### 🎯 ¿Qué problema resuelve?
¿Alguna vez te has preguntado cuánta gasolina vas a gastar en un viaje? Este modelo aprende de viajes anteriores para predecir con precisión el consumo de combustible, ayudándote a planificar mejor tus rutas y saber cuánto dinero necesitas para gasolina.

### 🚀 Características
- ✅ Simulación de datos realistas basados en el rendimiento de la Yamaha FZ 2.0 (45-50 km/litro)
- ✅ Implementación completa de Regresión Lineal con scikit-learn
- ✅ Visualización de resultados con gráficos profesionales
- ✅ Evaluación del modelo con métricas (MSE, RMSE, R²)
- ✅ Predicciones para escenarios reales (viajes cortos, medios, largos)
- ✅ Cálculo de costos aproximados de combustible
